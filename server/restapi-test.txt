## 🔐 Authentication Routes
**Base URL:** `/api/auth`

### 1. Register User
- **Endpoint:** `POST /api/auth/register`
- **Status:** `201 Created` / `400 Bad Request`

```bash
curl -X POST http://localhost:5000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "John Doe",
    "email": "john@example.com",
    "password": "password123",
    "role": "user"
  }'
```

**Response (201):**
```json
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "_id": "65a1b2c3d4e5f67890abcdef",
    "name": "John Doe",
    "email": "john@example.com",
    "role": "user",
    "token": "eyJhbGciOiJIUzI1NiIs..."
  }
}
```

### 2. Login User
- **Endpoint:** `POST /api/auth/login`
- **Status:** `200 OK` / `401 Unauthorized`

```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "john@example.com",
    "password": "password123"
  }'
```

**Response (200):**
```json
{
  "success": true,
  "message": "Login successful",
  "data": {
    "_id": "65a1b2c3d4e5f67890abcdef",
    "name": "John Doe",
    "email": "john@example.com",
    "role": "user",
    "token": "eyJhbGciOiJIUzI1NiIs..."
  }
}
```

### 3. Logout User
- **Endpoint:** `POST /api/auth/logout`
- **Status:** `200 OK`

```bash
curl -X POST http://localhost:5000/api/auth/logout \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**Response (200):**
```json
{
  "success": true,
  "message": "Logged out successfully"
}
```

### 4. Get Current User
- **Endpoint:** `GET /api/auth/me`
- **Status:** `200 OK` / `401 Unauthorized`

```bash
curl -X GET http://localhost:5000/api/auth/me \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**Response (200):**
```json
{
  "success": true,
  "data": {
    "_id": "65a1b2c3d4e5f67890abcdef",
    "name": "John Doe",
    "email": "john@example.com",
    "role": "user",
    "createdAt": "2024-01-15T10:30:00.000Z"
  }
}
```

### 5. Forgot Password
- **Endpoint:** `POST /api/auth/forgot-password`
- **Status:** `200 OK` / `404 Not Found`

```bash
curl -X POST http://localhost:5000/api/auth/forgot-password \
  -H "Content-Type: application/json" \
  -d '{"email": "john@example.com"}'
```

**Response (200):**
```json
{
  "success": true,
  "message": "Password reset email sent"
}
```

### 6. Reset Password
- **Endpoint:** `POST /api/auth/reset-password/:token`
- **Status:** `200 OK` / `400 Bad Request`

```bash
curl -X POST http://localhost:5000/api/auth/reset-password/eyJhbGciOiJIUzI1NiIs... \
  -H "Content-Type: application/json" \
  -d '{"password": "newpassword123"}'
```

**Response (200):**
```json
{
  "success": true,
  "message": "Password reset successfully"
}
```

### 7. Change Password
- **Endpoint:** `PUT /api/auth/change-password`
- **Status:** `200 OK` / `400 Bad Request`

```bash
curl -X PUT http://localhost:5000/api/auth/change-password \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "currentPassword": "password123",
    "newPassword": "newpassword123"
  }'
```

**Response (200):**
```json
{
  "success": true,
  "message": "Password changed successfully"
}
```

### 8. Refresh Token
- **Endpoint:** `POST /api/auth/refresh-token`
- **Status:** `200 OK` / `401 Unauthorized`

```bash

```

**Response (200):**

## 🔑 Authentication Header

For protected routes, include the JWT token in the Authorization header:

```bash
Authorization: Bearer YOUR_JWT_TOKEN
```

## 📝 Common Query Parameters

- `page` - Page number for pagination (default: 1)
- `limit` - Items per page (default: 10-20)
- `sort` - Sort field (e.g., `newest`, `oldest`, `popular`)
- `category` - Filter by category
- `type` - Filter by type (for audio/video)
- `q` - Search query

## 🚦 HTTP Status Codes

| Code | Meaning |
|------|---------|
| 200 | OK - Request successful |
| 201 | Created - Resource created |
| 204 | No Content - Request successful, no response body |
| 206 | Partial Content - Used for streaming |
| 400 | Bad Request - Invalid input |
| 401 | Unauthorized - Authentication required |
| 403 | Forbidden - Insufficient permissions |
| 404 | Not Found - Resource not found |
| 409 | Conflict - Resource already exists |
| 429 | Too Many Requests - Rate limit exceeded |
| 500 | Internal Server Error |
