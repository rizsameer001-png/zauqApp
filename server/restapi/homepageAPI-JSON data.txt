## 🔓 Public Routes (No Authentication Required)

### GET `/api/homepage/`
Get complete homepage data

**Response Status Codes:**
- `200 OK` - Success
- `500 Internal Server Error` - Server error

**Response Example:**
```json
{
  "success": true,
  "data": {
    "sections": [...],
    "featured": {...},
    "banners": [...],
    "quote": {...}
  }
}
```

## 🔑 Common HTTP Status Codes Summary

| Status Code | Meaning | When it occurs |
|-------------|---------|----------------|
| 200 OK | Success | GET, PUT, PATCH requests successful |
| 201 Created | Resource created | POST requests creating new resources |
| 400 Bad Request | Invalid request | Missing required fields, invalid data format |
| 401 Unauthorized | Authentication required | No token or invalid token provided |
| 403 Forbidden | Insufficient permissions | Valid token but not admin role |
| 404 Not Found | Resource not found | Requested ID or section doesn't exist |
| 500 Internal Server Error | Server error | Database error, server configuration issue |

## 📝 Headers Required for Admin Routes

```http
Authorization: Bearer <your_jwt_token>
Content-Type: application/json
```
