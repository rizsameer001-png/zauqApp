|--------|----------|-------------|

## 🔑 Important Notes

1. **Base URL**: All endpoints are prefixed with `/api/homepage` after the base URL
2. **Authentication**: Admin routes require authentication token (likely Bearer token in Authorization header)
3. **Admin Role**: Admin routes may also require admin privileges
4. **Query Parameters**: 
   - `/featured` accepts `?type=` parameter (values: poems, authors, books, audio, videos)
5. **Deprecation Warning**: Legacy routes are marked for deprecation - use admin routes (with `/admin` prefix) for new development
6. **Content-Type**: All POST/PUT/PATCH requests should send JSON data with `Content-Type: application/json`
