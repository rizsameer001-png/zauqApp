Here are the API URLs to test notification functionality:

## Notification API Endpoints

### Base URL: `http://localhost:5000/api/notifications`

### 1. User Notification Endpoints (Requires Authentication)

| Method | Endpoint | Description | Auth Required |
|--------|----------|-------------|---------------|
| **GET** | `/api/notifications` | Get user's notifications | ✅ Bearer Token |
| **GET** | `/api/notifications/unread-count` | Get unread notification count | ✅ Bearer Token |
| **PUT** | `/api/notifications/:id/read` | Mark single notification as read | ✅ Bearer Token |
| **PUT** | `/api/notifications/read-all` | Mark all notifications as read | ✅ Bearer Token |
| **DELETE** | `/api/notifications/:id` | Delete a notification | ✅ Bearer Token |
| **PUT** | `/api/notifications/preferences` | Update notification preferences | ✅ Bearer Token |
| **POST** | `/api/notifications/dismiss-notice` | Dismiss global notice | ✅ Bearer Token |

### 2. Public Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| **GET** | `/api/notifications/global-notice` | Get active global notice (homepage banner) |

### 3. Admin Endpoints (Requires Admin Role)

| Method | Endpoint | Description |
|--------|----------|-------------|
| **GET** | `/api/notifications/admin/all` | Get all notifications (admin view) |
| **GET** | `/api/notifications/admin/stats` | Get notification statistics |
| **GET** | `/api/notifications/admin/:id` | Get single notification by ID |
| **POST** | `/api/notifications/admin/create` | Send notification to users |
| **PUT** | `/api/notifications/admin/:id` | Update notification |
| **DELETE** | `/api/notifications/admin/:id` | Delete notification |
| **POST** | `/api/notifications/admin/bulk-delete` | Bulk delete notifications |
| **PUT** | `/api/notifications/admin/global-notice` | Update global notice |

## Testing with cURL Commands

### 1. Get User Notifications
```bash
curl -X GET http://localhost:5000/api/notifications \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 2. Get Unread Count
```bash
curl -X GET http://localhost:5000/api/notifications/unread-count \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 3. Mark Notification as Read
```bash
curl -X PUT http://localhost:5000/api/notifications/NOTIFICATION_ID/read \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 4. Mark All as Read
```bash
curl -X PUT http://localhost:5000/api/notifications/read-all \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 5. Delete Notification
```bash
curl -X DELETE http://localhost:5000/api/notifications/NOTIFICATION_ID \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 6. Update Preferences
```bash
curl -X PUT http://localhost:5000/api/notifications/preferences \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"enabled": true}'
```

### 7. Dismiss Global Notice
```bash
curl -X POST http://localhost:5000/api/notifications/dismiss-notice \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 8. Get Global Notice (Public)
```bash
curl -X GET http://localhost:5000/api/notifications/global-notice
```

### 9. Admin: Get All Notifications
```bash
curl -X GET "http://localhost:5000/api/notifications/admin/all?page=1&limit=20&type=announcement&status=unread" \
  -H "Authorization: Bearer ADMIN_JWT_TOKEN"
```

### 10. Admin: Get Notification Statistics
```bash
curl -X GET http://localhost:5000/api/notifications/admin/stats \
  -H "Authorization: Bearer ADMIN_JWT_TOKEN"
```

### 11. Admin: Send Notification to All Users
```bash
curl -X POST http://localhost:5000/api/notifications/admin/create \
  -H "Authorization: Bearer ADMIN_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "New Feature Alert!",
    "message": "We have added new books and poems to our collection.",
    "type": "announcement",
    "sendTo": "all",
    "priority": "high",
    "imageUrl": "https://example.com/image.jpg",
    "actionUrl": "/explore"
  }'
```

### 12. Admin: Send to Premium Users Only
```bash
curl -X POST http://localhost:5000/api/notifications/admin/create \
  -H "Authorization: Bearer ADMIN_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Premium Exclusive Content",
    "message": "New premium books are now available!",
    "type": "subscription",
    "sendTo": "premium",
    "priority": "normal"
  }'
```

### 13. Admin: Update Global Notice (Homepage Banner)
```bash
curl -X PUT http://localhost:5000/api/notifications/admin/global-notice \
  -H "Authorization: Bearer ADMIN_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Special Offer!",
    "message": "Get 30% off on annual subscription. Limited time offer!",
    "type": "promotion",
    "priority": "high",
    "actionUrl": "/subscription",
    "expiresAt": "2024-12-31T23:59:59.000Z",
    "active": true
  }'
```

### 14. Admin: Delete Notification
```bash
curl -X DELETE http://localhost:5000/api/notifications/admin/NOTIFICATION_ID \
  -H "Authorization: Bearer ADMIN_JWT_TOKEN"
```

### 15. Admin: Bulk Delete Notifications
```bash
curl -X POST http://localhost:5000/api/notifications/admin/bulk-delete \
  -H "Authorization: Bearer ADMIN_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "ids": ["NOTIFICATION_ID_1", "NOTIFICATION_ID_2", "NOTIFICATION_ID_3"]
  }'
```

## Query Parameters for Admin GET Endpoints

| Parameter | Values | Description |
|-----------|--------|-------------|
| `page` | number | Page number (default: 1) |
| `limit` | number | Items per page (default: 20) |
| `type` | announcement, system, subscription, follow, like, comment | Filter by type |
| `status` | read, unread, all | Filter by read status |
| `search` | string | Search in title/message |
| `startDate` | ISO date | Filter from date |
| `endDate` | ISO date | Filter to date |

## Quick Test with Postman

1. **Create a collection** named "Notification API"
2. **Add Authorization header**: `Authorization: Bearer YOUR_TOKEN`
3. **Test the endpoints** in this order:
   - GET `/api/notifications/unread-count`
   - GET `/api/notifications`
   - PUT `/api/notifications/read-all`
   - GET `/api/notifications` (verify all are read)

Remember to replace `YOUR_JWT_TOKEN` and `ADMIN_JWT_TOKEN` with actual JWT tokens from login, and `NOTIFICATION_ID` with actual notification IDs from the response.
