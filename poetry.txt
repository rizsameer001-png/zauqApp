## 9️⃣ **POST /poems/:id/like** - Like/Unlike a Poem

```bash
# Like a poem
curl -X POST "http://localhost:5000/api/poems/65a1b2c3d4e5f67890abcdef/like" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

# Unlike a poem (DELETE request)
curl -X DELETE "http://localhost:5000/api/poems/65a1b2c3d4e5f67890abcdef/like" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

**Sample Response:**
```json
{
  "success": true,
  "data": {
    "liked": true,
    "likesCount": 12501
  },
  "message": "Poem liked successfully"
}
```

## 🧪 **Complete Testing Script (Bash)**

```bash
#!/bin/bash

BASE_URL="http://localhost:5000/api"
TOKEN="YOUR_JWT_TOKEN_HERE"

echo "=== TESTING POETRY API ENDPOINTS ==="

# 1. Get all poems
echo -e "\n1. GET /poems"
curl -X GET "$BASE_URL/poems?page=1&limit=5"

# 2. Get trending poems
echo -e "\n2. GET /poems/trending"
curl -X GET "$BASE_URL/poems/trending"

# 3. Get featured poems
echo -e "\n3. GET /poems/featured"
curl -X GET "$BASE_URL/poems/featured"

# 4. Get single poem by slug
echo -e "\n4. GET /poems/hazaaron-khwahishein-aisi"
curl -X GET "$BASE_URL/poems/hazaaron-khwahishein-aisi"

# 5. Search poems
echo -e "\n5. GET /poems/search?q=ghalib"
curl -X GET "$BASE_URL/poems/search?q=ghalib"

# 6. Get related poems
echo -e "\n6. GET /poems/hazaaron-khwahishein-aisi/related"
curl -X GET "$BASE_URL/poems/hazaaron-khwahishein-aisi/related"

# 7. Get random poem
echo -e "\n7. GET /poems/random"
curl -X GET "$BASE_URL/poems/random"

# 8. Like poem (requires auth)
echo -e "\n8. POST /poems/:id/like"
curl -X POST "$BASE_URL/poems/65a1b2c3d4e5f67890abcdef/like" \
  -H "Authorization: Bearer $TOKEN"

echo -e "\n\n✅ API Testing Complete!"
```
